STRUCTURE

🧱 HTML: 건물의 뼈대를 세우는 '구조 정의'

HTML은 정보의 성격을 규정하는 마크업 언어입니다. 단순히 텍스트를 나열하는 것이 아니라, 브라우저에게 문서의 각 부분이 어떤 의미를 갖는지 정확히 안내합니다.

통찰: 시맨틱 마크업

검색 엔진 최적화(SEO)와 웹 접근성(A11y)의 핵심입니다. 태그 자체가 의미를 갖게 하여 기계와 사람 모두에게 아름답고 정확한 정보를 전달합니다.

태그 용도 및 특징
<h1>~<h6> 문서의 계층적 구조 정의 (SEO 필수 요소)
<strong>, <em> 의미론적 강조 (스크린 리더 완벽 대응)
<figure> 이미지와 캡션을 올바르게 그룹화
<abbr>, <ruby> 약어 설명 및 발음 보조 보조 장치
STYLE

🎨 CSS: 시각적 가치를 더하는 '디자인의 마법'

내용과 디자인을 완벽히 분리하여 유지보수 능력을 극대화합니다. 캐스케이딩(Cascading) 원칙을 통해 스타일의 우선순위를 결정하며, 현대 웹에서는 Flexbox와 Grid를 사용해 정교한 화면 배치를 구성합니다.

✓
Flexbox: 1차원 정렬 시스템 (메뉴바, 버튼 그룹 내 정렬에 특화)
✓
CSS Grid: 2차원 격자 레이아웃 (전체 레이아웃 및 대시보드)

.clay-card {

display: flex;

border-radius: 45px;

background: rgba(255,255,255,0.75);

backdrop-filter: blur(12px);

box-shadow: soft-pink-clay;

}

// Tailwind CSS를 필두로 한 유틸리티 클래스 최적화
